================================================================================
  e-Blood Flutter Backend Connection Fix
================================================================================

PROBLEM:
  The app was trying to connect to: https://e-blood-j14l.onrender.com/api/v1/api/donors/donors
  (note the double /api/) which caused 404 errors and failed API calls.

ROOT CAUSE:
  - ApiEndpoints.baseUrl default: 'https://e-blood-j14l.onrender.com/api/v1'
  - Repository paths included '/api/' prefix (e.g., '/api/donors/donors')
  - Result: Double /api/ in every API URL

FIX APPLIED:
================================================================================
1. Fixed API Base URL (lib/core/constants/api_endpoints.dart)
   - Changed default from: 'https://e-blood-j14l.onrender.com/api/v1'
   - Changed to:           'https://e-blood-j14l.onrender.com'

2. Fixed ALL Repository Paths (removed /api/ prefix):
   - lib/features/donors/data/donors_repository.dart
   - lib/features/blood_banks/data/blood_banks_repository.dart
   - lib/features/blood_requests/data/blood_requests_repository.dart
   - lib/features/profile/data/profile_repository.dart
   - lib/features/donation_history/data/donation_history_repository.dart

   Each path changed from: /api/xxxx/xxxx
   To:                       /xxxx/xxxx
